# Use Cases

This folder collects concrete agentic escrow use cases.

Each use case should explain why direct payment may be insufficient and what conditional settlement adds.

## Current Use Cases

| Use case | Core question |
| --- | --- |
| [Agent buys a product](agent-buys-product.md) | How does an agent purchase without releasing funds before delivery? |
| [Agent purchases compute](agent-purchases-compute.md) | When is direct machine payment enough, and when does escrow help? |
| [Agent hires another agent](agent-hires-agent.md) | How can autonomous services pay each other for outcomes? |
| [Enterprise procurement](enterprise-procurement.md) | How can company agents coordinate controlled vendor payments? |
| [Grants and bounties](grants-and-bounties.md) | How can agents help route milestone-based capital? |
